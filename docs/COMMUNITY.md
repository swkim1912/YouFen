## 0. 공통 원칙

### 0-1. 실명 노출 방지
- 커뮤니티(게시판·채팅·장터)에는 **닉네임·프로필 사진·티어 테두리·티어 뱃지만** 보인다. 등수(“에페 6위” 등)는 표시하지 않는다.
- 회원은 **커뮤니티에서 쓸 얼굴(프로필)**을 고른다.
  - **유펜 프로필 그대로**: 유펜 닉네임·사진. 카드를 누르면 유펜 프로필로 이동할 수 있다.
  - **커뮤니티 전용 프로필**: 커뮤니티 닉네임·사진. 카드를 눌러도 유펜 프로필·선수 페이지로 **연결되지 않는다.**
- 글·댓글·장터 글·채팅은 **쓸 때 고른 얼굴을 기억**한다. 나중에 설정을 바꿔도 예전 글의 표시가 다른 얼굴로 바뀌지 않는다
  (바뀌면 “전용 닉네임 = 유펜 닉네임”이 드러나기 때문).
- 커뮤니티 전용 프로필은 회원 id 대신 **별도의 공개 id**로만 화면에 나간다(차단·신고도 이 id 로).
- 오픈피스트 참가자 방은 예외로 **유펜 프로필**로 들어간다(입장 전 안내, “다시 보지 않기”).

### 0-2. 닉네임 규칙
- 형식: 2~12자 한글/영문/숫자(유펜 닉네임과 같음).
- 중복 금지 범위(대소문자 무시): **본인 포함 모든 회원의 유펜 닉네임 · 다른 회원의 커뮤니티 닉네임 · 모든 채팅 익명 닉네임 · 협회 선수 실명**.
  반대로 유펜 닉네임을 바꿀 때도 커뮤니티·채팅 닉네임과 겹칠 수 없다.
- 커뮤니티 닉네임은 **30일에 1번** 바꿀 수 있다(처음 정할 때는 제한 없음).

### 0-3. 프로필 사진
- 커뮤니티 전용 사진도 유펜 사진과 같은 서버 검사(Google Vision SafeSearch)와 제한(하루 2회 — **유펜·커뮤니티 사진 합산**, 전체 월 950건)을 쓴다.
- 사진 변경 제한(`avatar_locked`)은 두 사진에 함께 적용된다.

### 0-4. 이용 정지(커뮤니티)
- 관리자가 1일 / 7일 / 30일 / 영구 정지. **커뮤니티 기능 전체**(게시판·채팅·장터·1:1 채팅·오픈피스트 글)에 적용, 읽기는 가능.
- 정지된 회원에게 사유·기간·이의제기 방법(고객지원)을 알림과 커뮤니티 화면 안내로 보여 준다.
- 사이트 전체 로그인 정지(기존 `이용 정지`, Auth ban)와는 별개.

### 0-5. 신고·차단
- 신고 대상: 커뮤니티 프로필, 게시글, 댓글, 채팅 메시지, 장터 글, 1:1 채팅.
- 신고 사유: 욕설·비하 / 실명·개인정보 노출 / 음란·선정 / 광고·도배 / 사기·거래 문제 / 사칭 / 기타(+ 상세 500자).
- 같은 대상에 **서로 다른 회원 3명**이 신고하면 자동 임시 숨김(관리자가 복구 또는 삭제). 신고는 하루 20건까지, 같은 대상 중복 신고 불가.
- 첫 신고가 들어오면 관리자에게 알림.
- 차단: 차단한 회원의 글·댓글·채팅·1:1 채팅을 모두 숨기고, 나에게 알림·1:1 채팅을 보낼 수 없다. 익명 글의 작성자도 차단할 수 있다(누구인지는 알려 주지 않음).
  차단 목록은 커뮤니티 설정 탭에서 관리(최대 300명).

### 0-6. 관리자 권한
- 다른 회원의 글·댓글·채팅·장터 글 숨김/삭제.
- 익명 글·댓글·채팅의 실제 작성자 확인: **문제가 되거나 신고가 들어온 경우에만** 조회. 조회할 때마다 내부 기록(`admin_audit`)이 남는다(화면에는 노출하지 않음).
- 삭제는 실제로 지우지 않고 **숨김 처리 → 그 달 말일까지 보관 → 말일에 완전 삭제**. 말일 하루 전에 관리자에게 백업 알림(관리자 페이지에서 내보내기).
- 관리자는 운영 알림(신고, 오픈피스트 승인 요청, 백업 등)을 항상 받는다(끌 수 없음).

### 0-7. 알림
- 공용 알림 표(`notifications`) + 종류별 켜기/끄기(`notification_settings`).
- 종류: 내 글에 댓글 / 내 댓글에 답글 / 내 글 좋아요 **10·50·100개 돌파** / @멘션 / 1:1 채팅 새 메시지 / 장터 글 만료 예정(판매 7일 전, 구매 3일 전) / 오픈피스트 새 모집(종목·지역 직접 선택) / 이용 정지 안내(끌 수 없음) / 운영 알림(관리자, 끌 수 없음).
- 알림은 60일 뒤 자동 삭제. 화면은 상단 알림 버튼(오픈 기록 수락 요청과 같은 창)에서 본다. 실시간 연결 대신 페이지 이동·1분 간격으로 새로 읽는다(Realtime 동시 접속 한도 절약).

### 0-8. 시간 표시
- 오늘 쓴 글: 방금 / n분 전 / n시간 전, 그 이전: 날짜(올해는 `10.08`, 작년 이전은 `2025.10.08`).

## 1. 마이 펜싱 > 커뮤니티 설정 탭
- 커뮤니티 프로필 선택(유펜 프로필 / 커뮤니티 전용 프로필) + 미리보기 카드.
- 커뮤니티 전용 프로필: 닉네임(30일 1회), 사진(사진 올리기 / 기본 프로필 / 사진 없음).
- 티어 테두리·티어 뱃지 사용(상세 설정에서 이동). 티어가 없으면 표시되지 않는다.
- 알림 설정(종류별 켜기/끄기).
- 차단 목록(해제).
- 커뮤니티 이용 정지 중이면 사유·기간·이의제기 안내.

## 2. 게시판
- 말머리: 자유(기본), 대회, 장비, 기술, 에페, 플뢰레, 사브르, 학부모 — **복수 선택**. 보는 사람도 복수 선택 필터(합집합).
- 검색: 제목 / 내용 / 제목+내용.
- 탭: 전체(최신순, 공지 상단 고정) / **이번 주 인기**(최근 7일 좋아요 많은 글 20개 · 댓글 많은 글 20개).
- 목록: 말머리, 제목, 댓글 수, 좋아요 수, 조회수, “(수정됨)”, 작성 시각(0-8).
- 글쓰기: 제목(60자), 내용(5,000자), 말머리, **익명으로 쓰기**, 사진 **최대 3장**(아래 9장 용량 검토). 익명 선택 시 “문제가 될 경우에만 운영자가 작성자를 확인할 수 있습니다” 안내.
- 댓글: 답글은 한 단계까지. 익명 댓글 가능. 익명은 글마다 **익명1, 익명2…** 번호(같은 사람은 같은 번호), 익명 글쓴이의 댓글은 **“글쓴이”** 표시.
- 좋아요(1인 1회, 취소 가능), 신고, 차단.
- 모아보기: 내가 쓴 글 / 내가 쓴 댓글.
- 읽기도 **로그인 회원만**(개발 중 결정 — 실명 노출 방지·무단 수집 방지. 비로그인 읽기를 열려면 board_list/board_post 의 로그인 검사와 anon 실행 권한을 바꾼다).
- 탈퇴한 회원의 글·댓글은 지우지 않고 '탈퇴 회원'으로 남긴다(다른 회원의 댓글이 달려 있으므로 — 처리방침에 명시할 것).
- 공지: 관리자만, 익명 불가, 전체 탭 맨 위 고정.
- 도배 방지: 글 1분에 1개·하루 30개, 댓글 10초에 1개·하루 200개(시각은 서버 기준).
- 알림: 내 글 댓글, 내 댓글 답글, 좋아요 10·50·100 돌파, @멘션.

## 3. 장터 + 1:1 채팅
- 이용 대상: **선수 연결 회원 + 선수를 연결한 학부모·지도자**(= 연결 선수가 1명 이상인 계정). 표시는 커뮤니티 프로필.
- 상단 고정 면책 문구: “유펜은 거래 당사자가 아니며, 상품과 거래에 대한 책임은 판매자에게 있습니다. 선입금 요구에 주의하고, 마스크 인증(800N/1600N) 등 장비의 안전 상태는 직접 확인하세요.”
- 카테고리: 검·부품 / 마스크 / 도복 / 장갑 / 신발 / 가방 / 바디코드·전자장비 / 기타.
- **판매 글(팝니다)**: 사진 최대 10장 + 대표 사진 1장, 물품명, 카테고리, 종목(에페·플뢰레·사브르·공용), 가격(0원 = 나눔), 사용 기간, 상품 상태, 손·사이즈(카테고리에 따라 필요할 때만), 거래 가능 지역, 택배 가능 여부, 상세 설명.
  - 상태: 판매중 → 예약중 → 거래완료. “판매중만 보기” 필터.
  - 노출 6개월, 만료 7일 전 알림, 연장(6개월) **2회까지**, 연장하지 않으면 자동 숨김. 상세에 “게시일 · 자동 정리 예정일”.
- **구매 글(삽니다)**: 필수 = 찾는 물품명, 카테고리, 희망 가격대(최소~최대 또는 협의) / 선택 = 종목, 손, 사이즈, 허용 상태(새것·사용감 적음·상관없음), 거래 지역, 택배 가능, 설명 / 사진 1장(예시).
  - 판매 글과 같은 목록, [삽니다] 표시·필터. 카드에는 “희망 ○○~○○원”.
  - 상태: 구하는 중 → 구했어요. 노출 30일, 만료 3일 전 알림, 연장 가능.
  - 판매자가 **“제 물건 있어요”** → 구매자와 1:1 채팅 시작.
- 검색(물품명·설명) + 카테고리·종목·상태 필터.
- **1:1 채팅(쪽지)**: 장터 글에서 시작(“판매자와 채팅하기” / “제 물건 있어요”). 커뮤니티 프로필로 대화, 전화번호 등 연락처는 노출하지 않는다.
  사진 전송(용량 제한, 검사 없음 — 신고 처리), 메시지 1달 보관, 신고·차단, 새 메시지 알림.
- 장터 사진은 Vision 검사 없이 **신고가 들어오면 처리**한다.
- 개발 중 결정(2026-10-08):
  - **둘러보기는 로그인 회원 누구나**, 글쓰기·1:1 채팅·장터 사진은 선수 연결 회원만.
  - 구매 글 연장도 판매 글과 같이 **2회까지**(만료 3일 전부터, 한 번에 30일).
  - 만료된 글은 30일 동안 작성자에게만 보이며 연장할 수 있고, 그 뒤 삭제 처리 → 다음 달 1일 완전 삭제(사진 정리).
  - 1:1 채팅은 실시간 연결 대신 **화면이 열려 있는 동안 4초마다** 새 메시지를 가져온다(Realtime 동시 접속 한도 절약). 새 메시지 알림은 그 대화방의 안 읽은 알림이 없을 때만 1개.
  - 1:1 채팅 신고는 대화방 단위(대상 = 상대, 신고 사본 = 최근 메시지 30개). 장터 글 삭제 후에도 대화방은 1달간 남는다.
  - 1:1 채팅의 얼굴은 대화를 시작할 때의 커뮤니티 프로필로 고정(글쓴이는 장터 글의 얼굴).
- 글·채팅 본문에 전화번호 형식이 있으면 “연락처는 1:1 채팅을 이용해 주세요” 경고.

## 4. 단체 채팅(자유톡방)
- 방은 **1개**. 카카오톡 오픈채팅 느낌.
- 입장 시 **커뮤니티 프로필** 또는 **익명 닉네임**(기본 랜덤, 자유톡방 전용, 직접 설정 가능 — 중복 규칙 0-2) 중 선택, 입장 후에도 변경 가능.
- **첫 입장 시, 그리고 활동 프로필을 바꾼 뒤** 이용 규칙 동의:
  1. 펜싱 및 펜싱 정보와 관련된 이야기는 항상 환영입니다
  2. 반말 금지 (서로 아는 분들이어도 단톡방인 만큼 존칭 사용 부탁드립니다.)
  3. 다른 사람에게 불쾌함을 줄 수 있는 언어 사용 금지 (욕설 등)
  4. 실명 언급 금지 (유명인을 제외한 동호인과 같은 일반인의 실명)
  5. 비난 및 지나친 비판 금지
  6. 익명일지라도 타인의 신상에 대한 이야기 자제
  7. 펜싱과 거리가 먼 사담 자제
- @닉네임 멘션 알림. 사진 전송(용량 제한, 검사 없음). 메시지 **1달 보관**.
- 신고·차단, 관리자 메시지 삭제(“관리자에 의해 삭제된 메시지”).
- 실시간 전송은 Supabase Realtime(무료 한도 주의 — 9장 참고).
- 개발 중 결정(2026-10-08):
  - **읽기·쓰기 모두 로그인 회원**, 입장(규칙 동의) 후에 메시지를 본다. 정지된 회원은 읽기만.
  - 커뮤니티 프로필 = 지금 커뮤니티 설정(유펜/전용)의 얼굴. 익명 닉네임 카드는 **이름만**(사진·티어 테두리·뱃지 없음). 메시지마다 보낼 때의 얼굴(y/c/n)을 저장.
  - 익명 닉네임은 **10분에 1번** 바꿀 수 있고, 바꾸면 내 예전 메시지도 새 이름으로 보인다(이름을 바꿔 숨을 수 없음). 기본값은 '날쌘검객123' 같은 추천 이름.
  - 실시간은 DB 가 비공개 채널로 **"새 메시지 번호"만** 보내고 화면이 그 신호를 받아 가져온다(차단·숨김은 DB 가 걸러 줌, 회원은 채널에 직접 보낼 수 없음). 접속자 수는 presence(무작위 키). 신호를 놓친 경우를 대비해 1분(연결 끊김 시 15초)마다 확인.
  - 글 1,000자 또는 사진 1장, 도배 방지 1초 1개·1분 20개·하루 1,000개·30초 안에 같은 내용 반복 금지. 사진 하루 30장.
  - @멘션은 그 이름을 **지금 자유톡방에서 쓰는** 회원에게만 알림(최대 5명, 그 회원의 안 읽은 톡방 멘션 알림이 있으면 더 보내지 않음). 메시지 메뉴의 '@부르기'로 정확한 이름을 넣는다.
  - 신고는 메시지 단위(사본 = 그 메시지와 앞 10개), 3명 신고 시 자동 가림. 내 메시지 삭제 가능('삭제된 메시지'), 관리자 삭제는 '관리자에 의해 삭제된 메시지'. 관리자는 익명 닉네임도 지울 수 있다(다음 입장 때 새로 정함).
  - 관리자 현황에 최근 24시간 메시지 수·보낸 회원 수(Realtime 한도 관리용).

## 5. 오픈피스트
- 탭: 전체 / 에페 / 플뢰레 / 사브르(기본 = 가입 시 고른 종목). 빠른 필터: **이번 주(앞으로 7일)**.
- 모집글(선수 연결 회원만): 운동 제목, 종목 1개, 레벨(입문·초급·중급·상급 복수), 장소, 지역, 시작 일시, 진행 시간(1~5시간, 6시간 이상), 정원, 참가비, 상세 내용(예시: “장비 대여 여부, 취소 규칙 등을 적어주세요”), 오픈채팅방 링크(선택).
- 관리자 승인 후 게시, 신청이 오면 관리자 알림. 수정도 승인 필요 — **승인 전까지 기존 내용 유지**.
- **참가 신청**(정원 표시, 신청/취소), 참가자 전용 방(유펜 프로필로 입장, 입장 전 안내 + 다시 보지 않기).
- 주최자는 모집 종료·취소 가능. 시작 시각 + 진행 시간이 지나면 자동 종료. 종료·취소된 모집은 목록에서 자동 숨김.
- 새 모집 알림: 켜기/끄기 + **종목·지역 직접 선택**.

## 6. 관리자 페이지
- 신고 탭 통합: 프로필 사진 신고(기존) + 커뮤니티 신고(대상 미리보기·신고 수·처리: 숨김/삭제, 기각, 이용 정지 바로가기, 익명 작성자 확인).
- 회원 탭: 커뮤니티 정지(1·7·30일·영구, 사유 필수)·해제.
- 오픈피스트 승인 탭, 숨김 콘텐츠 백업(월말 전 내보내기).

## 7. 법률 문서
- 운영원칙 주소 이동: `/community` → `/guidelines` (`/community` 는 커뮤니티 화면이 생기기 전까지 `/guidelines` 로 보냄).
- 개인정보 처리방침·이용약관·운영원칙 개정(커뮤니티 프로필, 게시글·댓글·사진, 채팅 기록 1달, 1:1 채팅, 장터 사진, 익명 작성자 식별, 신고·차단·정지 기록, 숨김 콘텐츠 월말 보관)
  → `CONSENT_VERSION` 을 올려 **기존 회원 재동의**. 재동의가 여러 번 뜨지 않도록 **커뮤니티를 공개하기 직전에 한 번에** 반영한다.

## 9. 사진 첨부 — 운영·용량 검토 (2026-10-08 기준)
현재 사용량: DB 235MB(대부분 대회 경기 데이터), 저장소 0.4MB(클럽 마크), Vision 이번 달 1건. 무료 플랜 기준 한도: DB 500MB, 저장소 1GB, 전송량(egress) 월 5GB, Realtime 동시 접속 200·월 200만 메시지.

- **저장 용량**: 사진을 서버에서 긴 변 1280px webp(약 150~250KB) + 목록용 320px 썸네일(약 15KB)로 다시 만들면
  게시글 3장 ≈ 0.6MB, 장터 판매 글 10장 ≈ 2MB. 1GB 로 게시글 사진 약 1,500건 또는 장터 글 약 500건 수준 → 숨김 글 월말 삭제, 만료된 장터 글 사진 삭제, 채팅 사진 1달 삭제로 순환시켜야 한다.
- **전송량이 더 먼저 찬다**: 사진 있는 글 하나를 열 때마다 최대 0.6MB. 월 5GB = 사진 글 약 8,000회 열람. 목록에는 썸네일만 쓰고, 파일 이름을 바꾸지 않는 방식(새 사진 = 새 이름)으로 브라우저 캐시를 길게 둔다.
- **위치 정보 노출 위험**: 휴대폰 사진에는 촬영 위치(GPS)가 들어 있다. 반드시 서버(sharp)에서 메타데이터를 지우고 다시 저장한다(브라우저에서만 지우면 우회 가능).
- **요청 크기 한도**: Vercel 함수 요청 본문 4.5MB → 사진은 브라우저에서 줄인 뒤 **한 장씩** 서버로 보낸다.
- **DB 용량**: 글·댓글·채팅 텍스트는 작다(채팅 1달 보관, 알림 60일 삭제). 대회 데이터 증가분까지 감안해도 여유가 있으나 400MB 를 넘으면 점검.
- **Realtime(단체 채팅)**: 메시지 1건이 접속자 수만큼 집계된다. 100명 접속 × 하루 1,000건 ≈ 월 300만 → 무료 한도 초과. 동시 접속·메시지 수를 관리자 현황에서 보고, 커지면 Pro 플랜(월 $25: 저장소 100GB, 전송량 250GB, DB 8GB, Realtime 500 동시·500만 메시지)으로 올린다.
- **하루 업로드 한도**(제안): 게시판 사진 하루 30장, 장터 사진 하루 40장, 채팅 사진 하루 30장, 한 장 최대 5MB(줄이기 전).
  → 구현: 게시판 30 · 장터 40 · 1:1 채팅 30 · 자유톡방 30장(종류별 따로).
- **자유톡방 Realtime 사용량**(구현 기준): 메시지 1건 = 신호 1개 × 접속자 수 + 접속자마다 새 메시지 조회 1번. 접속·퇴장 때 presence 신호도 접속자 수만큼 나간다.
